# 04 · 공개 웹사이트 스펙 (고객용)

대상: 대리점(дэлгүүр) + 개인 고객. 로그인 없음. 밝은 "석고(plaster)" 테마 — 07 문서 참조.
목업 탭 01 기준. 기존 kkllc.vercel.app을 이 구조로 발전시킵니다.

## 페이지 구성

| 경로 | 내용 | Phase |
|---|---|---|
| `/` | 히어로 + 무료배송 배너 + 제품 카탈로그 + 장바구니 바 + 주문조회 티저 | P2 (정적 카탈로그는 지금도 가능) |
| `/cart` | 장바구니 상세 + 100ш 미터 + 주문 폼(이름·전화·지역구·주소) → `POST /api/orders` (source: 'website') | P2 |
| `/track` | 전화번호 입력 → 상태 컨베이어 표시 | P2 |

## 1. 상단 내비 (`.snav` — 네이비 바)

- 로고: 포대 SVG 아이콘 + `KK LLC`
- 메뉴: `Бүтээгдэхүүн · Хүргэлт · Захиалга шалгах · Бидний тухай`
- 우측 전화 칩: `☎ 7011-2233`

## 2. 히어로

- 헤드라인: `Үйлдвэрээс шууд. Таны барилгад — өдөртөө.`
- 서브: 자체 생산(замаск·цавуу), 대리점·개인 공급, **100+ш → УБ 시내 무료배송** 강조.
- 신뢰 지표 3개: `10+ жил` 경력 · `5 нэр төрөл` 제품 · `24 цаг` 내 배송.
- CTA: `Захиалга өгөх`(솔리드) / `Дэлгүүрт бөөний үнэ авах`(라인).

## 3. 무료배송 배너 (`.freebanner`)

- 좌: `100+ ширхэгт хүргэлт үнэгүй` + 소문구 `УБ хотын бүх дүүрэгт · Өөрийн ачааны машинаар · Ажлын өдөр 09:00–19:00`
- 우측 룰 칩: `100ш-ээс доош → хүргэлт 30,000₮`

## 4. 제품 카탈로그 (`products` 테이블에서 로드)

카드 구성: 포대 SVG(밴드 색상별) → `25 кг` 배지 → 이름 → 용도 → 가격 → 수량 스테퍼 → `Сагслах` 버튼.

| 제품 | 용도 문구 | 가격 | 밴드 색 |
|---|---|---|---|
| Цагаан замаск | Гүйцээх өнгөлгөө · дотор хана | 13,500₮ | #F4F1E8 |
| Хар замаск | Суурь тэгшилгээ · түрхэц | 9,500₮ | #2A2A2E |
| Блокны цавуу | Блок, хөнгөн бетон өрлөг | 8,900₮ | #3E9B6B |
| Плитаны цавуу | Плита, керамик наалт | 14,500₮ | #3D7DD8 |
| Knauf гипс | Албан ёсны борлуулалт | 28,000₮ | #0A9BDC |

가격은 플레이스홀더 — 실제 가격은 DB(`products.price_mnt`)에서만 관리.

## 5. 장바구니 바 (`.cartbar`) + 100ш 미터

- 상단: `Таны сагс` · 품목 요약(`Цагаан замаск ×20 · Блокны цавуу ×44 = 64ш`) · 합계(`661,600₮`).
- **미터**: BR-1의 `calcDelivery()` 결과로 렌더.
  - 미달: kraft색 바 + `Дахин 36 ширхэг нэмбэл хүргэлт ҮНЭГҮЙ болно — одоогоор хүргэлт 30,000₮.`
  - 달성: 초록 바 + 무료배송 배지.
- 주의: 미터는 총 수량이 아닌 **품목별 최대 수량** 기준(BR-1).

## 6. 주문조회 (`/track`, `.track` 섹션)

- 문구: `Бүртгүүлэх шаардлагагүй — захиалга өгсөн утасны дугаараа оруулаад явцаа хараарай.`
- 입력: 전화번호 → `Шалгах` → `GET /api/track?phone=`
- 결과: 최근 주문의 상태 컨베이어(5단계):
  `Бүртгэсэн → Жолоочид өгсөн → Ачсан → Замд явж байна → Хүргэгдсэн`
  (완료 단계 초록 ✓, 현재 단계 주황 점 + 펄스)
- 응답 필드 최소화: 주문번호, 상태, 품목 요약, 합계, 예정일. 주소·기사 개인정보 미노출.

## 7. 푸터 (`.sfoot`)

## 컴포넌트 목록

- `ProductCard` (포대 SVG + 스테퍼) — 포대 SVG는 `<symbol id="sack">` 재사용, `--band` CSS 변수로 색 지정
- `FreeDeliveryMeter` (사이트·관리자 공용 — props: items[], theme: 'light'|'dark')
- `StatusConveyor` (track 페이지 + 영수증 공용)
- `CartBar`, `TrackForm`

## 웹 주문 흐름

`/cart` 제출 → `POST /api/orders` (status: 'new', source: 'website') → 관리자 칸반 Шинэ 열에 실시간 등장(Supabase Realtime) → 이후는 관리자 플로우와 동일.
