# KK LLC 주문·배송 관리 시스템 — 개발 문서

Kokorozashi Kibou LLC (Улаанбаатар, 건축자재 제조·판매)의 3개 화면(공개 웹사이트 · 관리자 앱 · 기사 앱)을 하나의 파이프라인으로 묶는 시스템 스펙입니다.
UI 목업(`kk-llc-ui-mockups.html`)에서 확정한 내용을 개발용 문서로 분리했습니다.

## 사용 방법

1. 이 폴더 전체를 기존 Next.js 프로젝트(kkllc.vercel.app 리포)의 `docs/` 아래에 복사합니다.
2. Claude Code 등 AI 도구로 개발할 때 "docs/ 폴더의 스펙을 따라 구현해줘"라고 지시하면 그대로 참조합니다.
3. 구현 순서는 `08-roadmap.md`의 Phase 1부터 진행합니다.

## 시스템 한 줄 요약

> 주문 하나, 파이프라인 하나, 화면 셋.
> 관리자 보드·기사 폰·고객 조회 페이지가 **같은 DB, 같은 상태 언어**를 쓰기 때문에 서로 어긋나지 않습니다.

핵심 흐름: 주문 접수 → 관리자 등록 → 시스템 자동검증(100ш 규칙·재고·중량) → 기사 배정 + 푸시 → 적재 체크리스트 → 배송(전화·현금·사진 증빙) → 완료(재고 차감·리포트).
