## 신규 주문 드로어 (`NewOrderDrawer`)

우측 고정 패널. 필드:

1. **음성 버튼**(P3 자리): 주황 마이크, 누르면 펄스 + 트랜스크립트 박스. P1에서는 비활성 표시만.
2. 고객: 이름 / 전화(입력 시 `customers` 전화 검색 → 기존 고객이면 자동 채움) / 지역구 select / 주소
3. 품목: 제품 select + 수량 → 여러 줄 추가. 줄마다 `단가 × 수량` 자동 표시.
4. **자동 계산 영역**(입력 즉시 갱신):
   - 합계 `subtotal_mnt`, 총수량, 총중량
   - **100ш 미터**(웹과 동일 컴포넌트, 다크 테마) — 달성 시 `ҮНЭГҮЙ ХҮРГЭЛТ — 100ш давсан ✓`
   - 배송비 0 / 30,000₮
5. 결제: Бэлэн / Данс / Зээл
6. 하단 버튼: `Жолооч сонгох`(select) + `Захиалга үүсгэх`(kraft 솔리드)

### 음성 입력 목업 예시 (P3 구현 시 그대로)

트랜스크립트: 고객 Болд, 9911-8899, БЗД, Цагаан ×120 + Блокны ×50 → 자동 채움 필드에 파란 테두리 + `· дуунаас` 라벨. 합계 2,065,000₮, 4.3т, 무료배송 미터 충족. **저장은 관리자 확인 버튼으로만**(BR-8).

## 기사 배정 플로우

1. 카드 또는 드로어에서 기사 선택(`drivers` 활성 목록 + 오늘 적재량 표시).
2. **용량 검사(BR-5)**: 초과 시 경고 모달 `Майти 3.5т — энэ ачаа 5.0т → 2 рейс шаардлагатай`. 진행/취소 선택.
3. 확정 → `POST /api/orders/[id]/assign` → status `assigned` + FCM 푸시 발송:
   - title: `Шинэ хүргэлт #1030 хуваарилагдлаа`
   - body: `СХД · Блокны цавуу ×200 · 5.0т — 2 рейс`

## 페이지별 (P2)

- `Захиалга`: 전체 목록 + 필터(상태/기간/지역/기사) + 검색(전화·이름·번호)
- `Жолооч`: 기사·차량 CRUD, 오늘 적재/완료 현황
- `Нөөц`: 재고 수불(입고 등록, delivered 자동 차감 내역)
- `Харилцагч`: 주문 이력, Зээл 잔액 장부
- `Тайлан`: 일/월 매출, 제품별 판매량, 기사 KPI, падаан(영수증) 인쇄

## 접근 제어

`/admin/*` 미들웨어에서 세션 + `role='manager'` 확인, 아니면 로그인으로 리다이렉트.
