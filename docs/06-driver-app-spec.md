# 06 · 기사 앱 스펙 (PWA)

경로: `/driver`. 목업 탭 03 기준. **장갑과 햇빛** 환경 설계: 밝은 고대비 테마, 터치 타겟 최소 48px, 화면당 핵심 액션 1개.

## PWA 설정

- `public/manifest.json`: name `KK Хүргэлт`, display `standalone`, theme_color `#0E1B2E`, 아이콘 192/512.
- Service Worker: 오늘 배송 리스트 + 상세를 캐시(오프라인에서도 주소·전화 열람 가능). 상태 변경은 온라인 시 전송, 실패 시 재시도 큐.
- 설치: 기사에게 링크 전송 → "홈 화면에 추가". App Store 불필요.
- 로그인 후 `POST /api/push/register`로 FCM 토큰 저장 → 푸시 수신.

## 화면 1 · 오늘의 배송 리스트 (`/driver`)

- 헤더(네이비): `Сайн уу, {기사명}` + `Майти · 01-23 УБА · {날짜}` + 근무 배지 `АЖИЛД ✓`
- **푸시 토스트**(수신 시): `Шинэ хүргэлт #1030 хуваарилагдлаа` / `СХД · Блокны цавуу ×200 · 5.0т — 2 рейс`
- 통계 3칸: `хүргэлт`(오늘 건수) · `ачаатай`(적재 톤) · `дууссан`(완료)
- 리스트 섹션 3개(본인 `driver_id` 주문만, Realtime):
  - `Одоо явж байгаа` — en_route 카드(주황 강조 테두리)
  - `Дараагийн` — assigned
  - `Дууссан` — delivered
- 카드: `#번호` + 상태 태그 + 고객명 + `지역 · 주소` + 품목 요약 + 중량 + `ҮНЭГҮЙ` 칩 + 현금이면 `Бэлэн {금액}₮`

## 화면 2 · 주문 상세 + 적재 (`/driver/orders/[id]`)

- 미니 컨베이어: `Хуваарилсан ✓ → [Ачиж байна] → Замд → Хүргэгдсэн`
- **전화 버튼**(풀폭, 네이비): `{고객명} — залгах` + 번호 → `tel:99112233`
- **지도 박스**: 핀 + `Газрын зураг нээх ↗` → Google Maps deep link
  `https://www.google.com/maps/dir/?api=1&destination={lat},{lng}` (좌표 없으면 주소 문자열 검색)
- **적재 체크리스트** (`Ачилтын жагсаалт · {총수량}ш`):
  - 행: 큰 체크박스(26px+) + 제품명 + `Багц {batch_no} · 25кг` + `×{qty}`
  - 탭 → `PATCH order_items.loaded` 저장(오프라인이면 로컬 큐)
- **하단 대형 버튼**: 미완료 시 회색 비활성 `Бүгдийг ачсаны дараа — Замд гарах` → 전부 체크되면 주황 활성 `Замд гарах →` → 상태 en_route (BR-3/BR-4)

## 화면 3 · 배송 진행/완료

- 미니 컨베이어: `… Ачсан ✓ → [Замд] → Хүргэгдсэн`
- **현금 카드**(네이비, 금액 크게): `Бэлнээр авах дүн — 1,837,500₮` + `Тоолж аваад доор тэмдэглэнэ — падаан менежер дээр автоматаар үүснэ`
- **사진 타일**(점선): `Зураг авах — Буулгасан ачааны баталгаа · заавал 1 зураг`
  → 카메라 → Storage `delivery-proofs/{order_id}/` 업로드 → `proof_photo_url` 저장 (BR-6)
- 보조 버튼 2개: `☎ Залгах` / `⚑ Асуудал мэдэгдэх`(note 남기고 관리자 알림)
- **완료 버튼**(초록, 사진 업로드 전 비활성): `✓ Хүргэгдсэн гэж тэмдэглэх` → status delivered → 재고 차감·리포트(BR-3)

## API 사용 요약

| 동작 | 호출 |
|---|---|
| 오늘 리스트 | Supabase select (RLS: 본인 주문만) + Realtime 구독 |
| 적재 체크 | `update order_items set loaded = …` |
| 출발 | `PATCH /api/orders/[id]/status` `{status:'en_route'}` (서버가 전 품목 loaded 검증) |
| 사진 업로드 | Storage upload → `PATCH orders.proof_photo_url` |
| 완료 | `PATCH /api/orders/[id]/status` `{status:'delivered'}` (서버가 사진 검증) |
| FCM 토큰 | `POST /api/push/register` |

## UX 원칙

- 버튼 텍스트는 동사형 몽골어, 14px+ 굵게. 상태 색은 02 문서 매핑 그대로.
- 실패해도 막히지 않게: 업로드 실패 시 재시도 안내, 지도는 외부 앱 위임, 전화는 OS 다이얼러.
- 다크모드 불필요 — 주간 야외 사용이 기본이므로 밝은 고대비 고정.
